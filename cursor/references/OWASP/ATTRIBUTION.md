# OWASP adaptation attribution

NightFalcon's files in this directory are concise adaptations of OWASP project category lists for security-review routing. Category names and identifiers derive from sources recorded in `/owasp-provenance.json`; explanatory language and cross-framework routing are NightFalcon adaptations.

OWASP documentation projects are generally licensed under [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). These adaptations are distributed under that license. Changes: condensed category descriptions, normalized identifiers, added review signals, and added cross-framework mappings. OWASP and project contributors do not endorse NightFalcon.

Exception: OWASP Kubernetes Top Ten, MCP Top 10, and Smart Contract Top 10 source material is CC BY-NC-SA 4.0. NightFalcon does not bundle or adapt those document bodies; index and graph contain identifier-and-title reference metadata linked to official sources.
